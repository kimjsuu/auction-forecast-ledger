# 법원경매 '비슷한 물건이 팔린 가격대(참고)' — 사전 고정 장부

이 저장소는 매각기일 **전에** 적어 둔 예상 범위 기록의 지문(SHA-256)과 그날 새로 적은 행을 날마다 올리는 곳입니다.
한 번 적은 행은 고치거나 지우지 않습니다. 입력값(최저가·기일)이 바뀌거나 오류가 확인되면 같은 (사건·물건·기일)에 **정정 행(rev+1)을 덧붙이고**,
채점은 기일 전날까지 적힌 마지막 행으로 하며 앞선 행은 성적표에 '대체됨(superseded)'으로 따로 집계합니다. 결과가 나온 뒤 실제 낙찰가와 비교한 성적표 요약을 함께 둡니다.

- `bid_predictions_hash.txt`: 날짜 · 적은 시각 · 전체 행수 · 그날 새 행수 · 전체 파일 SHA-256 · 그룹표 태그 · 코드 버전 · 사슬 해시(어제 사슬 + 오늘 해시)
- `predictions/YYYYMMDD.csv`: 그날 새로 고정한 예측 행(사건번호·물건번호·용도·지역·매각기일·감정가·최저가·저감단계·깃발·시세(있으면)·그룹·표본 수·P10/P25/중간/P75/P90·화면 표시 여부·버전·최저가 출처·정정 차수). 개인정보 없음
- `scorecard_summary.json`: 최신 성적표 요약(headline = 기일 하루 전까지 적힌 마지막 행만, superseded = 대체된 행, corrections = 정정 기록)

이 범위는 **과거에 비슷한 조건(용도·지역·저감단계)으로 팔린 물건들의 낙찰가/최저가 통계**입니다. 이번 기일에 팔릴지, 얼마에 팔릴지를 보장하지 않으며
감정평가·시세·권리분석·입찰 추천·법률 자문이 아닙니다. 산식과 표본 수는 각 행에 적혀 있습니다.

  - 영향: 11/3·11/4에 고정한 v0.2 행 중 유찰≥1 물건(약 2/3)의 범위가 25~43% 높게 적힘. 기존 행은 지우지 않고 같은 (사건·물건·기일)에 정정 행(rev 1)을 덧붙임. 채점은 기일 전날까지 적힌 마지막 행으로 하고, 대체된 행은 성적표에 'superseded'로 따로 집계
